# $SWAP artwork map

Every live asset is in `assets/` as a compressed WebP image. The matching full-resolution PNG source is in `source-art/`. Artwork is original and generated specifically for this project.

| Asset | Website usage |
|---|---|
| `hero-banner.webp` | Wide branded SWAP banner |
| `swap-logo.webp` | Header and footer circular logo |
| `shiba-hero.webp` | Transparent Shiba mascot for homepage |
| `letter-s.webp` | First photo mosaic letter |
| `letter-w.webp` | Second photo mosaic letter |
| `letter-a.webp` | Third photo mosaic letter |
| `letter-p.webp` | Fourth photo mosaic letter |
| `story-red.webp` | Sad Shiba / red candle story |
| `story-green.webp` | Celebrating Shiba / green candle story |
| `rocket-launch.webp` | Ethereum rocket narrative scene |
| `rocket-alt.webp` | Alternate rocket illustration (optional) |
| `shiba-trader.webp` | About section trader artwork |
| `community-party.webp` | Community crowd artwork |
| `community-rooftop.webp` | Alternative community background (optional) |
| `get-eth.webp` | How to Buy, ETH step |
| `buy-swap.webp` | How to Buy, token swap step |
| `hodl.webp` | How to Buy, manage/hold step |
| `tokenomics.webp` | Tokenomics background |
| `footer-rooftop.webp` | Footer illustration |

The How to Buy wallet step is drawn with CSS to keep text sharp and avoid misleading wallet branding. `assets/favicon.png` is generated from the circular logo.

## Photo-letter technique

The photo-collage letters remain independent WebP assets, allowing animations and responsive scaling as in the reference site's iconic letter treatment. The original full-size generated art remains in `source-art/`.
